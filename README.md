# Running on Perlmutter

[run.sh](https://github.com/y-song/O2Physics/blob/master/run.sh) runs over [PWGJE/Tasks/jetFinderQA.cxx](https://github.com/y-song/O2Physics/blob/master/PWGJE/Tasks/jetFinderQA.cxx), taking in [aimeric_config.json](https://github.com/y-song/O2Physics/blob/master/aimeric_config.json) as config and `559613/AO2D_013.root` as input file  
`559613/AO2D_013.root` can be found on Perlumtter at `/global/cfs/cdirs/alice/youqi/O2Physics/559613/AO2D_013.root`  
Run output looks like `/global/cfs/cdirs/alice/youqi/O2Physics/559613/559613_013.log`  
Output file looks like `/global/cfs/cdirs/alice/youqi/O2Physics/559613/AnalysisResults_559613_013.root`
